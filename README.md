# Laboratorio de ideas

Sitio del Laboratorio de ideas de Micaela Cañal: en 5 días y sin reuniones, un plan de acción para tu producto o tu idea.

- `index.html`: la estructura de la página.
- `lab.js`: todos los textos (español e inglés) y el formulario.
- `lab.css`: estilos (mismos tokens que el portfolio).
- `assets/brote/`: el ejemplo de Brote (cliente ficticio).

Se publica con GitHub Pages desde la rama `main`.
